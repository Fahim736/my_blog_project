# Django Blog Application

A full-featured Blog Application built with Django, featuring user authentication, post management, commenting, and rating functionality.

## Features

- **User Authentication:** Registration, Login, and Logout functionality.
- **Post Management:** Create, view, edit, and delete blog posts.
- **My Posts Page:** Dedicated dashboard for authors to manage their own posts.
- **Comment System:** Users can add comments on individual blog posts.
- **Rating System:** Users can rate posts to share their feedback.
- **Namespaced Routing:** Clean URL structure using `blog:` namespaces.

## Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3, Bootstrap 5
- **Database:** SQLite3
